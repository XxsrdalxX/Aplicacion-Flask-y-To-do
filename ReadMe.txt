FLASK: 
Para ejecutar la app flask tienes que  entrar a la carpeta llamada flask y al archivo llamado ASD.py, seguido de esto vas a la terminal de 
visual studio code y verificas que el entorno virtual este activado, en caso de que no colocas el siguiente comando en la terminal 
./venv/script/acivate  luego de esto instalas las librerias con el comando  pip install -r ./requirements.txt.
El siguiente paso es ejecutarlo escribiendo en la terminal (py Flask/ASD.py) al iniciar el programa te aparecera una url como esta:
(http://127.0.0.1:5000) la copias en el navegador. OPCIONAL: Existe un apartado en la ruta (http://127.0.0.1:5000/inicio) para un contenido 
diferente a la ruta original.
